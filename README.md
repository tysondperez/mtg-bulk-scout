# Searchlight - An MtG Bulk Search Tool <img src="https://cafans.b-cdn.net/images/Category_78028/subcat_141340/9g5APIl3_1606161255291gpadd.jpg?class=sitethumb" alt="Searchlight" width="100">

Do you build too many MtG decks? Do you hate trying to figure out which sets which cards were printed in? Do you wish there was a better way to search through your bulk for entire decks at the same time? Wish no more.

Searchlight is a tool to help you bring your online MtG decks to life by simplifying the search for cards that you might already own.

Paste a decklist or two (or twenty) into the textbox and watch as each card is queried using Scryfall's API to check which set(s) it was printed in. The results will be determined by trying to use the fewest possible number of sets, to minimize the time it takes to search through your bulk.

There are several filters and toggles you can use to help customize the tool to your specific collection, and help you keep track of which cards you've found along the way.
